# South Africa Labour Market Analytics Dashboard

## Project Overview

An interactive four-page Power BI dashboard developed to analyse approximately 63K South African labour-market records.

## Data Source

Statistics South Africa (Stats SA)
Quarterly Labour Force Survey (QLFS)

## Objectives

- Analyse employment and unemployment
- Analyse workforce demographics
- Examine gender and education patterns
- Analyse provincial labour-market trends
- Monitor data quality and missing values
- Present insights through interactive Power BI dashboards

## Dashboard Pages

### 1. Labour Market Overview
Provides an overall view of employment, unemployment, demographics, education, gender and sector.

### 2. Employment & Unemployment
Examines employment status, unemployment by gender and province, and education-related employment patterns.

### 3. Workforce & Demographics
Analyses workforce characteristics by age, gender, education, occupation and industry.

### 4. Data Quality & Insights
Evaluates missing values, field-level data quality and overall dataset completeness.

## Key Finding

Overall data quality was approximately 73%, with Working Hours and Employment Status showing notable missing data.

## Data Limitation

Occupation and Industry Codes remain numeric because descriptive code mappings were not available in the source dataset.
